Speed

        

          
          
          
          
        

        

        

          Insane is a benchmark setting, against a receiver you own. The receiver decides how many
          associations it will accept, and going past that limit gets the extras rejected. A rejected
          association is retried, so this usually does not arrive as a slower run or as a shortfall between
          instances found and acknowledged: it arrives as a run that reports a narrower parallelism than the
          sixteen it asked for, at the bottom of the output. A study also has to split into at least sixteen
          chunks before sixteen associations can run at once, so a small one runs narrower than this no matter
          what the receiver allows.
        


        

          
          
        

        

          
        

        

          
          
          
        


        

          Advanced 
          

            
A preset sets both of these together, because setting one alone caps the other.
              A chunk size typed here replaces the preset's half of that and leaves its association count in
              place — the command carries both flags and the engine names what it displaced. An association
              count typed here replaces the preset outright: the command drops --speed, because a
              preset that has lost its width would still be sizing the chunks off your number. Clear the field
              to go back to the preset.

Modality Worklist

          
Ask what's scheduled, then perform a step against a folder of images.

        

        

          
The query is a C-FIND at worklist level and changes nothing on the SCP. Scheduling filters go inside the Scheduled Procedure Step Sequence, which is what a conformant MWL SCP expects — a flat query is the usual reason a worklist comes back empty.

          
Performing a step is one dcm mpps perform transaction: N-CREATE opens the step, C-STORE sends the images, N-SET closes it. COMPLETED requires every instance found on disk to have been acknowledged.

Speed test

          
Send the same study repeatedly and compare. Each run uses its own calling AE Title, so you can pick it out of the peer's ingress logs.

        


        

          
        


        


        
What to compare

        

          
          
          
          
        


        

          

            
            
            
            
            
            
          

        


        

          

            
          

        


        

          

            
            
            
            
          

          

          

            
          

        


        

          

            
          

        


        

          
          
        


        

        

          
          
          
        


        

        

        

        
Throughput is measured against bytes on disk, so compressing a study does not flatter the number. "On the wire" is what the network actually carried. Which transfer syntax is used is the peer's choice — the table shows what it negotiated, not just what was asked for. Width is measured the same way: it is the associations the peer actually had open at once, not the number the run asked for, and it is a floor — it can read one low on a run whose last chunks drain early, and never reads high.

Connect to Claude

          
Let Claude (or any MCP client) drive these DICOM operations as tools, using the same engine this app runs.

        


        

          Checking whether dcm is on your PATH…
        


        
Claude Code (terminal)

        
Run this once. It registers the server so Claude Code can call it.

        

          claude mcp add dcm-dicom -- dcm mcp
          
        


        
Claude Desktop

        
Add this to your claude_desktop_config.json (Settings → Developer → Edit Config), then restart Claude.

        

          
{
  "mcpServers": {
    "dcm-dicom": { "command": "dcm", "args": ["mcp"] }
  }
}

          
        


        
What Claude can then do

        

          
dcm_echo Test a peer connection (C-ECHO).

          
dcm_inventory Inventory a folder — studies, series, sizes.

          
dcm_query Query a peer (C-FIND).

          
dcm_tags Inspect DICOM tags.

          
dcm_send Send a study (C-STORE), with found/sent/acknowledged accounting.

          
dcm_anon De-identify a folder.

          
dcm_edit Change or remove tags into a new folder.

        

        
Requires dcm installed and on your PATH (the same command this app uses). If claude mcp add isn't found, install Claude Code first.
