De-identify a folder

          
Copy a folder with identifiers removed and UIDs remapped. The source is never modified.

        

        

          Best-effort, not certified. It does not read pixel data, so burned-in
          annotations survive, and identifiers inside nested sequences (SR, presentation states) can
          survive. Always inspect a sample before sharing anything this produces.
        

        

          
        

        

          
        

        

          
        

        

          
          
        

        

        

          
          
        

        

      


      
      

        

          
Connect to Claude

          
Let Claude (or any MCP client) drive these DICOM operations as tools, using the same engine this app runs.

        


        

          Checking whether dcm is on your PATH…
        


        
Claude Code (terminal)

        
Run this once. It registers the server so Claude Code can call it.

        

          claude mcp add dcm-dicom -- dcm mcp
          
        


        
Claude Desktop

        
Add this to your claude_desktop_config.json (Settings → Developer → Edit Config), then restart Claude.

        

          
{
  "mcpServers": {
    "dcm-dicom": { "command": "dcm", "args": ["mcp"] }
  }
}

          
        


        
What Claude can then do

        

          
dcm_echo Test a peer connection (C-ECHO).

          
dcm_inventory Inventory a folder — studies, series, sizes.

          
dcm_query Query a peer (C-FIND).

          
dcm_tags Inspect DICOM tags.

          
dcm_send Send a study (C-STORE), with found/sent/acknowledged accounting.

          
dcm_anon De-identify a folder.

          
dcm_edit Change or remove tags into a new folder.

        

        
Requires dcm installed and on your PATH (the same command this app uses). If claude mcp add isn't found, install Claude Code first.
